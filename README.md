🛒 Shopping Cart Application

A simple and responsive shopping cart built using vanilla HTML, CSS, and JavaScript.
No frameworks, no dependencies — runs completely in the browser.

🚀 Tech Stack

HTML5

CSS3 (Vanilla CSS)

JavaScript (ES6)

✨ Features

Display products with name, image, and price

Add/remove items from cart

Increase or decrease item quantity

Real-time cart item count

Automatic subtotal, shipping, and total calculation

Responsive design (desktop, tablet, mobile)

Runs locally without setup

🧩 How It Works

Products are displayed on page load

Clicking Add to Cart adds or updates the item

Cart icon opens the cart sidebar

Quantity buttons update cart instantly

Cart summary recalculates in real-time

📁 Project Structure
shopping-cart/
├── index.html
├── styles.css
├── script.js
├── images/
└── README.md

▶️ Run the Project

No installation needed

Just open:

index.html


in your browser
(Optional: use a local server for best results)

⚙️ Configuration

Shipping Cost

Add Products
Update the products array in script.js
